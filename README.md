# Royal Crest Booking

Create a complete professional and attractive hotel room booking website called “Royal Crest Hotel” using HTML, CSS, and JavaScript.

The website should have these sections:

1. Home

2. About

3. Rooms

4. Dining

5. Facilities

6. Book Now

7. Contact

8. Location

Design Requirements:

- Make the website look modern, elegant, luxurious, attractive, and professional.

- Use a single elegant luxury hotel background image/theme consistently throughout the entire website.

- The same background should continue across all sections/pages without looking disconnected.

- Use a dark luxury theme with complementary gold, cream, white, and dark brown/black colors.

- Use stylish modern fonts and clean typography.

- Add smooth animations, hover effects, transitions, and attractive buttons.

- Make the website fully responsive for laptop, tablet, and mobile.

Rooms Section:

Create attractive room cards with:

- Room image

- Room name

- Short description

- Facilities

- Price per night

- “Book Now” button

Include different rooms such as:

- Deluxe Room

- Premium Room

- Executive Suite

- Royal Suite

Keep the room prices reasonable and affordable for a hotel booking website.

Book Now:

Create a professional booking form with:

- Guest Name

- Email

- Phone Number

- Check-in Date

- Check-out Date

- Number of Guests

- Room Type

- “Confirm Booking” button

Add JavaScript validation and a booking confirmation message after submission.

Other Sections:

- Home: attractive hero section with hotel name and “Book Your Stay” button.

- About: short description about Royal Crest Hotel.

- Dining: elegant restaurant and dining information.

- Facilities: swimming pool, restaurant, Wi-Fi, gym, parking, room service, etc.

- Contact: phone, email, address and contact form.

- Location: attractive location/map section.

Important:

Use the SAME background throughout the FULL WEBSITE. Do not give each section a different background.

Make the final website visually impressive, clean, premium, easy to navigate, and suitable for a college project presentation/demo.
